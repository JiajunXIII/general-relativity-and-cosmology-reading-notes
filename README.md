# General Relativity and Cosmology Reading Notes

这是一个关于广义相对论与宇宙学的 Obsidian 阅读笔记仓库，主要整理教材阅读过程中的章节笔记、概念卡片和推导解释。

当前笔记以 Weinberg 风格的相对论与宇宙学材料为主，内容覆盖非欧几何、引力理论历史、相对性原理、Lorentz 变换、时间膨胀、粒子动力学、四动量、矢量与张量等主题。

## Contents

仓库按 Obsidian vault 组织：

- 根目录 Markdown：章节级阅读笔记和入口页。
- `Concepts/`：术语、记号和核心概念说明，例如 Lorentz boost、四动量、Minkowski 度规、协变矢量与逆变矢量。
- `Explanations/`：句子、段落、公式和推理链的详细解释，例如公式推导、物理含义辨析、记号转换原因。
- `.obsidian/`：基础 Obsidian 配置，便于直接作为 vault 打开。

## How to Read

推荐用 Obsidian 打开本仓库：

1. 将仓库 clone 到本地。
2. 在 Obsidian 中选择 `Open folder as vault`。
3. 从 `欢迎.md` 或根目录章节笔记开始阅读。
4. 通过 wikilinks 跳转到 `Concepts/` 和 `Explanations/` 中的补充说明。

也可以直接在 GitHub 上阅读 Markdown 文件。数学公式使用 Markdown/Obsidian 常见的 `$...$` 和 `$$...$$` 形式保存。
